# Biblioteca Digital UniFECAF

Primeira interface web da Biblioteca Digital UniFECAF, feita só com HTML e CSS para a disciplina Design Web.

- **Site publicado:** https://pauloot.github.io/biblioteca-unifecaf/
- **Vídeo pitch:** [LINK DO VÍDEO]

## Estrutura

```
biblioteca-unifecaf/
├── index.html          estrutura e conteúdo (HTML semântico)
├── css/
│   └── style.css       layout, cores, tipografia e responsividade (mobile-first)
└── assets/
    └── imagens/        ilustrações próprias em SVG
```

## Seções

Menu · Banner · Sobre a nossa biblioteca (com 4 serviços) · Destaque · Nossos livros (6 cards) · As unidades · Contatos · Rodapé

## Como abrir

Abra o `index.html` no navegador. Não há etapa de build nem dependências.
